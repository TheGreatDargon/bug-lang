# bug-lang

Have you ever been frustrated trying to figure a bug while coding? Well, I am writing a new language called bug language. If you assumed that this language would help you find bugs well you are sorely mistaken; this language is designed to remove bugs in the most diabolical way ever. The idea behind how this language will work is that when the programming language encounters a bug that it would normally flag for the user it will instead just silently drop it from the AST. Did you forget the unclosed " on your string? Well your string didn't print. The foundational principal of the language is that it will always run no matter what, this program will never panic, and it will never crash; If it needs to remove all of your code for it to accomplish this, so be it.
